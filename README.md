## Agent Town

A tiny town where three agents go about their day:

- **Ada** the Researcher reads at the library and writes notes at the café.
- **Bo** the Builder buys wood at the market and builds a bench for the park.
- **Cy** the Messenger carries Ada's notes to Bo and sorts the mail.

To try it, download `index.html` and open it in any web browser. Click an agent to follow it, and use the buttons to pause or speed things up.
